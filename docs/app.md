# Приложение или сайт

Интерфейс Выверки с ноября 2026 года устроен как приложение, а не как сайт: постоянная боковая панель, один экран —
одна задача, подробности открываются окнами поверх, длинной прокрутки нет. Вопрос, стоит ли переносить Выверку
в отдельную программу, разобран ниже.

## Что важно для решения

- **Поиск цен идёт с сервера.** Запросы к ЕИС, зеркалу реестра и каталогам, кэш страниц и копии доказательств
  удобнее держать в одном месте, а не на каждом рабочем месте.
- **Настройки общие для отдела.** Утверждённый список источников, пороги методики и журнал решений должны быть
  одинаковыми у всех закупщиков. Иначе два человека получат разную НМЦД по одному ТЗ.
- **Рабочие места разные.** В вузах и госзаказчиках встречаются Windows, Astra Linux и РЕД ОС; браузер по умолчанию
  есть везде, права на установку программ — не везде.
- **Вход по учётной записи организации.** Проще сделать один раз на сервере, чем в каждой копии программы.

## Варианты

| | Веб-приложение (сейчас) | Установка из браузера (PWA) | Настольная сборка (Tauri + сервер) | Полностью локальная программа |
|---|---|---|---|---|
| Что видит пользователь | вкладка браузера | своё окно и значок, без адресной строки | установщик, своё окно | установщик, своё окно |
| Нужен сервер | да | да | да, общий | нет |
| Общие настройки и журнал | да | да | да | нет, у каждого свои |
| Работа без сети | нет | нет | нет | частично (поиск цен всё равно нужен) |
| Обновление | сразу у всех | сразу у всех | установщик или автообновление | у каждого отдельно |
| Права на установку | не нужны | не нужны | нужны | нужны |
| Работы | готово | готово: манифест и значки | 2–3 недели | 2–3 месяца |

Оценки работ — для одного разработчика, знакомого с кодом; включают сборку, подпись и проверку на трёх ОС.

## Решение

1. **Сейчас — установка из браузера.** В Яндекс Браузере, Chrome и Edge в адресной строке появляется
   «Установить приложение»: Выверка открывается в своём окне со значком в панели задач. Сделано: манифест
   `static/manifest.webmanifest`, значки 192 и 512 px, быстрые действия «Новый расчёт», «Расчёты», «Настройки».
2. **Дальше — настольная сборка поверх того же сервера.** Оболочка Tauri 2 (окно на системном WebView, установщик
   10–15 МБ) открывает адрес сервера организации; для одиночного рабочего места сервер на Python собирается
   PyInstaller и запускается как sidecar. Сборки: MSI для Windows, `.deb` для Astra Linux, `.rpm` для РЕД ОС.
   Интерфейс тот же, поэтому второй кодовой базы не появляется.
3. **Полностью локальную программу не делать.** Она разрывает общие настройки и журнал, а поиск цен без сети
   всё равно не работает. Это плата без выигрыша.

## Что сделать для настольной сборки

- Вынести адрес сервера в первый запуск программы (поле «Адрес Выверки в вашей организации»).
- Собрать сервер PyInstaller в один файл, проверить, что шаблоны, статика и кэш находят свои пути.
- Конфигурация Tauri: окно 1280×800, минимальная ширина 1024, запрет навигации за пределы адреса сервера,
  сохранение файлов DOCX и XLSX через системный диалог.
- Подпись сборок, автообновление из внутреннего хранилища организации.
- Проверка на Windows 10/11, Astra Linux 1.8, РЕД ОС 8.
- Для закупки в госсекторе — оценить включение в реестр российского ПО.
